# 资产管理使用说明

> 对应模块 `quant/portfolio/`；数据库 `data/portfolio.db`（与行情库 `quant.db` 分开存）
> 界面：主窗口第七页「资产管理」；命令行：`quant portfolio-*`

## 1. 概念

    资产账户（王大）                          ← 一个人
    └── 资金账户（华泰证券 / 国金证券 / 天天基金）  ← 券商或基金账户，有自己的币种
        └── 持仓（600519 × 100 股）          ← 数量 + 成本价
            └── 产品（股票 / 场内基金 / 场外基金 / 现金）← 风险等级挂在这里

- **风险等级挂在产品上**，不是挂在持仓上。同一只股票出现在两个账户里，风险等级只有一份。
- **现金也是产品**，每个币种一条（人民币 / 港币 / 美元现金），风险固定低风险。
- 市值口径统一为「数量 × 价格」，现金的数量就是金额、价格恒为 1。

## 2. 币种与市场

| 市场 | 币种 | 行情来源 |
| --- | --- | --- |
| `CN` A股 | CNY | 本地 `quant.db` 的 `daily_price` |
| `CN` 场内 ETF | CNY | 本地 `etf_daily`（只有几十只）→ 缺了联网取 |
| `CN` 场外基金 | CNY | akshare `fund_open_fund_info_em` |
| `HK` 港股 | HKD | 新浪 `stock_hk_daily`（接口保留，当前以 A 股为主） |
| `US` 美股 | USD | 东财 `stock_us_hist`（接口保留，当前以 A 股为主） |

**汇率**用中国银行牌价的「中行折算价」（单位是 100 外币兑人民币，入库时除以 100），
存在 `portfolio_fx_rate` 表；某天查不到就用最近一条，一条都没有时按 1:1 兜底并告警。

**统计口径**：所有汇总金额折算成人民币（`BASE_CURRENCY`）。

## 3. 风险等级

| 产品类型 | 默认风险 |
| --- | --- |
| 股票 | 高风险 |
| 场内基金 / 场外基金 | 中风险 |
| 现金 | 低风险（不建议改） |

新建产品时按上表给默认值，之后可在界面上按产品改（`viewmodels.portfolio_set_risk`）。

## 4. 价格与刷新

价格优先级：手动价 / 最近一次刷新价 > 没有价格（显示「缺价格」）。

> 没有价格时**不会拿成本价冒充现价**——那样浮动盈亏永远是 0，会骗自己。
> 缺价格的产品不计入总资产，界面会提示「N 个产品缺价格」。

刷新入口：界面标题条「刷新价格与汇率」，或 `quant portfolio-update`。
联网失败（网络抖动很常见）不会清空已有价格，只会出现在失败列表里，重试即可。
### 基金（场外基金 / 场内 ETF / LOF / 封闭基金）怎么拿净值

资产页「持仓」页签右侧有一个 **「更新基金净值」** 按钮，它**只拉你持有的基金**，
不会去拉全市场几千只基金，也不动股票和汇率。

**怎么判断一个持仓算不算基金？不只看「产品类型」字段**，还会看代码：

- 6 位数字且以 **1**（深市 LOF/ETF）或 **5**（沪市 ETF/LOF）开头 → 一律当基金处理
- 所以 `161130`（白银期货 LOF）、`510300`（沪深300ETF）即使录入时类型选成了「股票」，也能刷到
- `600519`、`000001` 这种真正的股票不会被基金刷新碰到

| 类型 | 主源 | 兜底 |
| --- | --- | --- |
| 场外基金 `kind=fund` | akshare `fund_open_fund_info_em`（单位净值） | 场内价 |
| 场内 ETF / LOF / 封闭基金 | 新浪 `fund_etf_hist_sina`（收盘价） | 净值；东财 `fund_etf_hist_em` 作最后兜底 |
| 本地行情库已有数据 | 本地最新价（快、不联网） | — |

**主源失败会自动换另一个源**，所以净值接口挂了还能用场内价兜住，反之亦然。
同一只基金被多个账户持有时只拉一次。价格写回产品表后，
**持仓市值 = 份额 × 价格** 立刻算出来，不用再点别的。

> 封闭基金常常有折溢价：比如 161130 净值 4.336、场内价 4.649。
> 系统取的是**场内价**（你能真正卖出的价格）。想按净值算，需要手动改产品价格。

命令行等价写法：

    quant portfolio-update --funds-only            只刷持有中的基金（含 ETF/LOF）
    quant portfolio-update --funds-only --no-etf   只刷场外基金

### 价格取哪个：本地库还是刚拉的净值？

**按日期比，取更新的那个。**
以前是「本地行情库优先」，会出现刚拉完基金净值、市值却还用着半年前本地旧价的情况。
现在两边都查，日期新的胜出；只有一边有就只用那一边。

## 5. 交易

| 操作 | 说明 |
| --- | --- |
| **买入** | 数量增加；成本按**移动加权平均**重算，**买入手续费计入成本**；同币种现金自动扣减 |
| **卖出** | 数量减少；**卖出手续费从卖出金额里扣**；现金自动加回 |
| **数量调整** | 直接把持仓设成目标数量 + 成本价，用于**期初导入**或修正送股 |
| **存入 / 取出** | 只动现金，写一条 deposit / withdraw 流水 |
| **删除买入 / 卖出** | 在「流水」页选中一条记录 →「删除选中」；按剩余流水重算持仓成本，并冲回对应现金 |

规则：

- 卖出数量超过持仓 → **直接拒绝并提示**，不会变成负数。
- 买入后现金为负 → 允许（可能只是没录初始资金），但会给警告。
- 卖出时结算**已实现盈亏** `(卖价 − 成本价) × 数量 − 手续费`，记在流水里。
- 删除买入 / 卖出流水后，持仓数量与成本按**剩余流水**重建，后续卖出的已实现盈亏同步修正；
  如果删除后持仓会变成负数（这笔买入已被后面的卖出用掉），会**拒绝删除**并提示先处理卖出记录。
- 只支持删除买入 / 卖出；数量调整请用「数量调整」修正，现金存取请用存入 / 取出。

### 期初导入怎么做

第一次使用不用补历史买入流水，直接用「数量调整」录入当前持仓：

    quant portfolio-adjust --account 华泰证券 --symbol 600519 --name 贵州茅台 --quantity 100 --cost 1400 --date 2024-01-02

`--date` 是**建仓日**，也是分红计算的起点（这之前的除息不算给你）。

## 6. 分红

### 数据来源

| 类型 | 来源 |
| --- | --- |
| A股个股 | 东财 `stock_fhps_detail_em`（含除权除息日、每 10 股派现/送转、方案进度） |
| 场内 ETF / 场外基金 | 东财 `fund_fh_em`（一次拉全量，按代码筛） |
| 港股 | 东财 `stock_hk_dividend_payout_em`（文本方案需解析，接口已保留） |
| **美股** | **无可靠免费源，只能手动登记** |

东财接口超时或返回空页时，A 股个股会自动改用巨潮资讯（`stock_dividend_cninfo`）再试一次；
拉取失败还会短暂重试，避免网络抖动导致「明明有分红却提示没取到」。

拉取：界面「拉取分红」按钮，或 `quant portfolio-dividend --refresh`。

拉取完成后「分红」和「分红预期」两个页签都会自动重算；如果提示「拉取失败：…」，是网络或东财接口
临时不可用，稍后重试即可；提示「没有分红记录」才是该产品在数据源里确实没有分红（ETF 被误录成
`stock` 时也会自动改走基金分红接口）。

> 旧版本数据库升级后，历史分红行没有「报告期」，会退回按除息日窗口统计。点一次「拉取分红」即可补齐报告期。

### 计算口径（重要）

1. **金额 = 除权除息日的每股分红 × 当天持股数量**。
2. 持股数量由**交易流水重建**；「数量调整」导入的持仓以导入日为起点。
3. 「分红」页按**除息日**归属年度；「分红预期」按**报告期（财报年度）**归集。
4. **税前**金额，不扣红利税。
5. 送股 / 转增只记录比例用于提示，**不会自动改持仓数量**（避免数据源出错时悄悄改坏账）。

### 会不会自动变成现金？

**不会。** 除息日和到账日常常差几天，自动入账会和真实银行流水对不上。
在分红列表里选中一行点「记入现金」（或 `quant portfolio-dividend --record <id> --account 华泰证券`），
才会生成一笔 `dividend` 流水并标记为已入账。

### 一年分红预期（按完整财报年度）

按**当前持仓**估算未来一年大概能收多少分红：

    预期年度分红 = 最近一个完整财报年度的每单位分红合计 × 当前持股数量

规则：

- 分红按**报告期**归入财报年度（例如 2025-06-30 中报、2025-12-31 年报都属于 2025 年度）。
- 优先使用最近一个**含年报分红**的完整年度；如果最近年度只披露了中报，则回退到上一年度。
- 如果某年度没有年报分红记录，到了下一年 6 月底仍没有，就按该年度已结束处理（只有中报/季度分红也算完整）。
- 一个年度内分红几次都会**全部加总**（次数不固定，可能 1 次、2 次或更多）。
- 指定年度时也是按**财报年度**统计，不是按除息日年份。
- A 股个股必须带报告期；旧数据缺少报告期时不会退回旧的除息日窗口，而是提示重新拉取分红。
- ETF / 场外基金没有报告期，仍按除息日窗口（默认近 12 个月）统计。
- 现金不参与计算；年化股息率 = 预期分红 ÷ 当前市值（缺价格的产品为空）。
- 明细表会显示使用的「分红年度」和「分红次数」，方便核对。

以 601919 为例：

- 2025 年度：中报每 10 股派 5.6 元 + 年报每 10 股派 4.4 元 = **每 10 股 10 元**；
- 2026 年度目前只有中报每 10 股派 4.3 元，**未完整**，因此预期沿用 2025 年度；
- 等 2026 年报也分红后，会自动改用完整的 2026 年度。

界面：资产管理 →「分红预期」页签，选资金账户和口径，点「重新计算」。
命令行：

    quant portfolio-dividend --forecast                 最近完整年度
    quant portfolio-dividend --forecast --year 2025     指定 2025 财报年度
    quant portfolio-dividend --forecast --months 24     仅对没有报告期的基金生效

> 这是**估算**，不是承诺：公司少分红、你减仓、送转股、红利税都会让实际到账金额变化。
> 如果整张表都是 0，说明还没拉过分红数据，先跑一次 `quant portfolio-dividend --refresh`。

### 手动登记（美股或数据源缺漏）

    quant portfolio-dividend --add AAPL --market US --ex-date 2026-02-07 --per-share 0.25 --report-period 2025-12-31

`--report-period` 建议按财报年度填写（例如 `2025-12-31`），这样「分红预期」才能正确归年；
不填时该笔只能按除息日窗口参与基金口径的统计。

## 7. 风险占比统计

`Portfolio.risk_breakdown()` 输出三行（高 / 中 / 低）：

| 列 | 含义 |
| --- | --- |
| `value` | 该风险等级的市值（折算人民币） |
| `weight` | 占全部市值的百分比（总市值 ≤ 0 时统一给 0） |
| `count` | 该等级下有几个持仓 |
| `missing` | 其中有几个缺价格（没算进市值） |

界面是「总览」页的环形图 + 明细表，也可以用 `quant portfolio-stats`。

## 8. 命令行速查

    quant portfolio-init                                  建库
    quant portfolio-owner --add 王大                       建资产账户
    quant portfolio-account --owner 王大 --add 华泰证券     建资金账户（默认 CNY）
    quant portfolio-account --owner 王大 --add 盈透证券 --currency USD
    quant portfolio-cash --account 华泰证券 --deposit 200000
    quant portfolio-buy  --account 华泰证券 --symbol 600519 --quantity 100 --price 1500 --fee 15
    quant portfolio-sell --account 华泰证券 --symbol 600519 --quantity 50 --price 1700
    quant portfolio-adjust --account 华泰证券 --symbol 510300 --kind etf --quantity 10000 --cost 3.9
    quant portfolio-position --refresh                     持仓 + 总资产（先刷价）
    quant portfolio-stats                                  总资产 + 风险占比
    quant portfolio-txn --limit 50                         交易流水（含流水 id）
    quant portfolio-txn --delete 12                        删除一条买入/卖出记录并重算持仓
    quant portfolio-update                                 刷汇率 + 所有持仓价格
    quant portfolio-update --funds-only                    只刷持有中的基金净值 / ETF
    quant portfolio-dividend --refresh --year 2025         拉分红并按年汇总
    quant portfolio-dividend --record 12 --account 华泰证券 把某笔分红记入现金

## 9. 常见问题

**Q：明明有分红，分红预期里还是 0？**
先点「拉取分红」，拉取完成会自动重算「分红预期」页。如果提示「拉取失败：…」通常是网络/接口
临时问题，重试即可；如果提示「没有分红记录」而该产品确实有分红，请先确认代码、市场、产品类型是否
正确，也可以手动登记：`quant portfolio-dividend --add 000408 --ex-date 2026-09-04 --per-share 1.0 --report-period 2025-12-31`。

如果明细里显示的是「无现金分红」，说明该财报年度只有送转、没有现金分红；如果显示的分红年度比
当前年份早，是因为最近年度只披露了中报，系统按「最近一个完整财报年度」回退了。

**Q：现金变成负数了？**
说明只录了买入、没录初始资金。用 `portfolio-cash --deposit` 补上即可；界面总览也会橙色提示。

**Q：某个产品一直显示「缺价格」？**
A股/ETF 先跑一次 `quant update-price` 把行情补进来；场外基金净值来自 akshare，网络不通会失败，重试即可。

**Q：ETF 取价经常失败？**
本地 `etf_daily` 只覆盖几十只 ETF，其余要联网取东财接口，网络抖动时会失败，多刷几次。

**Q：买入 / 卖出记录录错了怎么办？**
到「流水」页选中那条记录，点「删除选中」（或右键选「删除这条买入 / 卖出记录」）。
系统会按剩余流水重算该产品的持仓数量与成本，并冲回对应现金；如果这笔买入已经被后面的卖出用掉，
会拒绝删除并提示先处理卖出记录。命令行：`quant portfolio-txn --delete <id>`。

**Q：能删账户吗？**
能，但会**连带删除其下的持仓与流水**。界面没有直接入口（避免误删），用 `quant portfolio-account --delete <id>`。

**Q：能做资产曲线吗？**
目前没有每日快照，画不了资产曲线。需要的话要另外加一个「每日记账」任务。
## 10. 界面操作速查（第一次使用）

界面入口：主窗口左侧导航「资产管理」。五个页签：总览 / 持仓 / 流水 / 分红 / 分红预期。

### 第一次使用，按这个顺序点

1. **总览页** → 点「新建资产账户」→ 填名字（例如 `王大`，这是「人」）
2. **总览页** → 点「新建资金账户」→ 选资产账户、填名称（例如 `华泰证券`）、选类型和币种
3. **持仓页** → 上方「资金账户」下拉里选中刚建的账户
4. **持仓页** → 点「存入现金」把账户里的钱录进去（不录也能买，但现金会变负数）
5. **持仓页** → 点「买入」录入新交易；已有持仓不想补历史流水，点「数量调整」直接录当前持股和成本价
6. **标题条** → 点「刷新价格与汇率」，把最新价和汇率拉下来（联网，可能几十秒）
7. **总览页** → 看总资产、各账户市值和高中低风险占比

### 各按钮在哪

| 想做什么 | 位置 |
| --- | --- |
| 新建资产账户（人） | 总览页左上「新建资产账户」 |
| 新建资金账户（券商） | 总览页左上「新建资金账户」 |
| 存钱 / 取钱 | 持仓页「存入现金」/「取出资金」 |
| 买入 / 卖出 | 持仓页「买入」/「卖出」 |
| 期初导入、修正数量 | 持仓页「数量调整」 |
| 删除录错的买入 / 卖出 | 流水页选中一行 →「删除选中」（或右键该行） |
| 刷新行情价格 | 标题条「刷新价格与汇率」 |
| 拉分红 | 分红页「拉取分红」 |
| 分红入账 | 分红页选中一行 → 「记入现金」 |

> 在持仓页点任何操作前，**必须先在上方下拉里选中一个资金账户**，否则会提示「请先选择资金账户」。

> 界面暂时没有「删除账户」入口（避免误删连带清空流水），要删请用命令行 `quant portfolio-account --delete <id>`。
